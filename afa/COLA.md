# 在 Cola 中使用 AFA DTC Skills

本目录是 AFA DTC 的入口 Skill `afa`，其余 30 个 `afa-*` 模块与它平级。系统共 31 个模块，由 `afa` 负责一级路由。

## 安装到 Cola

把本仓库里所有 `afa*` 文件夹（共 31 个）整体复制到 Cola 的技能目录：

- macOS：`~/.cola/skills/`
- Windows：`%USERPROFILE%\.cola\skills\`

复制后目录应形如：

```text
~/.cola/skills/
├── afa/
├── afa-aov/
├── afa-brand/
├── ...
└── afa-tt/
```

注意：31 个文件夹必须在同一层，模块之间用 `../afa-*` 相对引用；多套一层或少一层都会断链。只装其中几个也能用，未安装模块的跨模块引用会自然失效，核心协议不受影响。

复制完成后重启 Cola 或新开一个会话，说「用 afa 帮我做独立站诊断」即可进入。

## 演示提示词

| 你说 | 系统会做什么 |
| --- | --- |
| 我想做独立站，还什么都没有 | 从零起步：市场验证 → 竞品 → 定位 → 产品 → 上市 |
| 我想做一件代发，先开个测试店快速测品 | 测试店快速测品：赢品验证 → 48 小时上线 → Day-0 冷启动 |
| ROAS 从 3 掉到 1.8 了 | 全链路诊断：拆漏斗定位病灶，再给带优先级的处方 |
| 黑五怎么准备 | 大促备战：产品策略 + 广告 + 落地页 + 邮件短信三线并行 |
| 帮我算这个 SKU 的真实利润 | 运行单位经济脚本，六层成本（含关税）逐层拆解 |
| Stripe 把我的货款冻结了 | 支付风控：冻结应对 SOP + 申诉材料清单 + 现金流预案 |

## Brand Brain

首次使用会在**当前工作目录**创建 `./brand-brain/`，用于保存品牌定位、产品、受众、竞品、指标等长期记忆。后续模块共享这份记忆，不需要重复交代背景。
