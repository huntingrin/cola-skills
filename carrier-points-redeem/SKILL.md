# 三网积分兑换

技能已预装。本文件在根目录；子流程路径相对 GUIDE。不查安装位置、不装依赖、不读 README；缺件报告路径。

## 先分流，再补信息

优先复用当前任务已有的运营商、手机号、用途、面额、商品和数量，不重复提问。

- **联通纯话费方法**：直接输出 [话费文字](skills/cucc-points-redeem/references/phonefee-text.md)；无需手机号、GUIDE、浏览器或发短信。混合请求再继续商城分支。
- **只问操作方法**：读对应 GUIDE 后说明步骤，不收手机号、不登录。
- **查询或兑换**：两项都缺时问“请告诉我你的运营商和手机号，例如：移动 13800138000”；只缺一项只补该项。用途明确直接执行；不明先只读查询，不自行选品或扣分。
- **继续 / 验证好了 / 已到账**：先找本任务断点，恢复原页面并只读核对，不重走下单。断点不足以识别账户时再补信息。

运营商别名：移动 / 中国移动 / CMCC / Mobile；联通 / 中国联通 / CUCC / Unicom；电信 / 中国电信 / CT / Telecom / 天翼。**不要用号段推断运营商**；明确为广电或虚拟运营商时请用户确认支持的实际运营商。

手机号去空格、连字符；仅当去前缀后为 11 位时移除 `+86` 或 `86`，再校验 `^1[3-9][0-9]{9}$`。无效只重问手机号。完整号码只用于本次账户核对；回复、日志、断点一律用 `138****8000`，不落盘。

## 浏览器执行

- 登录只用一个任务页；已有页接续，无页才 open 一次，超时不重复 open。后台操作，不抢键鼠或接管无关页。Ego 复用原任务页；Cola 始终带 `profile="cola"` 和原 `targetId`。参数不清读 [Cola 适配](references/browser.md)。
- **新查询/兑换默认未登录，先按 GUIDE 到登录表单。** 无任务页才打开完整登录 URL，已有页原地接续；不先逛商城、查旧登录态或检查 UA/日期。表单出现就交接本人，确认后核对账户。同笔恢复沿用原页面。
- 业务页每阶段读一次快照，取得号码、积分、商品、现金、规则和 refs；页面变化更新 refs，缺字段定向补读。复杂页或登录/验证阶段用无输入值摘要，按需读 [页面摘要](references/observe.md)。
- 登录须有可见输入框和提交按钮，URL/标题不算成功；落首页按 GUIDE 原页点登录，不能交接首页。空白按 GUIDE 恢复。业务等 5–15 秒，最多补等一次；空白不当 0。下单、扣分、短信不批量或重试；能力不足说明，不擅自换浏览器。

## 共同业务约束

- **只办本机，现金补款必须为 0 元。** 登录后比对页面脱敏号码与预期号码；不一致或无法核实就停止下单。页面提示非本运营商账户时不反复登录。脱敏标识只能核对可见位，不能宣称完整号码已独立核验。
- 手机号、密码、图形码、短信验证码由本人在官网填；不索取聊天中的验证码、不读输入框值、短信、Cookie 或凭据。用户截图不另存、不转发。
- “看看”只读；明确兑换并指定商品/面额即沿用本笔授权，不重复选品。下单前一次告知实际积分和现金；积分不足、现金项、规格变化、超预算或异常成本时停下说明，不用历史比例补齐价格。未指定的试兑按子流程处理，不默认清空余额。
- 不办套餐变更、抽奖、实物、提现、代充、现金购买或自动续订。未读清关键规则不得提交。

## 一条断点与结果

连续查询不落盘，交接仅留页面断点。首次可能建单或扣分前，在任务私有目录留一条记录：业务及授权、脱敏账户、商品/面额/数量、积分/现金、profile/targetId 或 spaceId/页面标签、阶段、尝试时间、已有订单号、下一步。后续更新同一条。不存验证码、完整号码或带 Token 网址，不写安装目录；正常流程不运行状态脚本、不拆多份 JSON。

已提交、处理中、超时或结果不明时，只读查原页面和订单，**不重复提交**，不通过新记录绕过旧尝试。同笔不并行；联通/电信需跨进程保护才用原状态脚本，共用原记录；移动无此脚本，保持串行。旧交易只作历史，新业务须有自己的授权。

简短报告：运营商及脱敏账户、兑换内容、实际积分/现金、订单号及平台状态、到账证据、下一步。未知就写未知。**扣积分不等于到账**；区分已提交、平台完成、用户确认到账、运营商或权益明细独立核验。只问方法时直接给方法，不套订单报告。
