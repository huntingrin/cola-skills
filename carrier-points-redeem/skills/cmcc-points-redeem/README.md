# 中国移动积分兑话费 Skill

让具备浏览器能力的 Agent 使用现有 AI 豆兑换本机话费，并处理短信交接、扣豆及到账核对。限**现金补款0元**的话费兑换。

## 安装与使用

```sh
git clone https://github.com/huntingrin/cmcc-points-redeem.git
```

将仓库作为 `cmcc-points-redeem` 文件夹放入你的 Agent 技能目录，具体目录以宿主文档为准。也可让 Agent 直接读取 [GUIDE.md](GUIDE.md)。

示例指令：

> 使用 cmcc-points-redeem，帮我用现有移动积分试兑一次最小面额话费，不补现金，并核对结果。

只查询可说：“查一下我的移动AI豆能兑换多少话费，先不兑换。”指定金额可说：“兑换5元本机话费，现金补款必须为0。”

## 使用前提

- 有中国移动号码、适用的现有AI豆，以及能导航、读页面、填表和点击的浏览器 Agent。
- 用户本人在官方网页完成登录；兑换时可能还需一次短信确认。验证码不要发聊天。
- 不依赖特定浏览器插件、模型、操作系统、Node.js、私有API或 Cookie 导出。遵守所在 Agent 的浏览器权限与后台操作规则。

普通AI豆与商城专属AI豆不可混算；最低面额、兑换比例与省份规则以账户页面为准。兑换不是赚取新积分，也不是现金提现。

## 实测范围

2026-10-12 已在电脑网页与 Ego 浏览器中完成登录后读取余额、准备零现金兑换、确认弹窗和短信交接，用户随后确认话费到账。短信后的积分余额和到账流水未由 Agent 再次独立核验，不能称为完全无人值守测试。其他 Agent、号码和省份未逐一实测。

技能保留“用户确认到账”与“独立流水核验”的区别，防止把提交、扣豆或短信弹窗误报为到账。断线恢复先查结果，不重复兑换。
