# 中国电信积分兑话费 Skill

新任务默认未登录，直接打开 [GUIDE 的完整登录地址](GUIDE.md#登录直达)。本人完成登录后读取本机积分和当前面额，再按授权办理**本机话费直充**。登录页可用桌面环境打开，移动 UA 只在登录后、下单前检查。

**范围固定为话费直充。** 不办理流量、语音、影音会员、云盘会员、金豆签到、生日礼包、实物或短信直兑。面额、积分和资格以本次官网页面为准，不预置静态商品表。

## 最短路径：2 次短信

| 步骤 | 动作 | 短信 |
|---|---|---|
| 1 | 直接打开 GUIDE 的完整登录 URL，等待登录表单 | — |
| 2 | 本人登录商城 SSO（`m.telefen.com`） | 第 1 次 |
| 3 | 读积分、面额和规则；需要兑换时设置移动 UA 和视口 | — |
| 4 | 选面额，点一次「兑换」进入收银台 | — |
| 5 | 核对积分/现金，点「确认支付」 | 第 2 次 |
| 6 | 查积分余额、订单状态、到账 | — |

**不要先登录星级中心，也不要登录 PC 账号 `login.189.cn`。** 两条路都会多一次短信，且不会让话费页免登录。

## 关键修复：移动 UA

移动版话费页在桌面 UA 下创建订单后，收银台可能回跳 `jf.189.cn/pchome`。先直达登录页并由本人登录；**点“兑换”建单前**设置移动环境，再在同页加载专区。不能因设备能力不足而阻止打开登录页：

```js
await page.cdp("Emulation.setUserAgentOverride", {
  userAgent: "Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Version/17.0 Mobile/15E148 Safari/604.1",
  acceptLanguage: "zh-CN,zh;q=0.9", platform: "iPhone",
});
await page.cdp("Emulation.setDeviceMetricsOverride", {
  width: 390, height: 844, deviceScaleFactor: 3, mobile: true,
});
```

如果已经跳回 PC 首页：**停止点兑换**，切移动 UA，查订单；只继续支付一笔，其余关闭。重复点击会生成多笔待支付订单。

## 安装

```sh
git clone https://github.com/huntingrin/ct-points-redeem.git ~/.codex/skills/ct-points-redeem
```

`GUIDE.md` 位于目录根下，整个目录就是一个子技能文件夹。其他宿主放入对应的技能目录即可，也可让具备浏览器能力的 Agent 直接读取 [GUIDE.md](GUIDE.md)。

## 非本技能范围

流量、语音、影音会员、天翼云盘、金豆签到、生日礼包、短信直兑、实物配送、代他人充值、分期返还话费和业务抵用金。需要这些能力时另建技能，不在此技能里扩展。

## 运行要求

- 宿主具备浏览器导航、读取页面、填写和点击能力，并遵循其页面所有权、后台操作及人工交接规则。
- 新任务默认未登录，直达官方登录表单；本人完成登录和支付验证，同笔复用本次页面，无需导出 Cookie。
- 可选的本地提交保护脚本使用 Python 3 标准库，文件锁依赖 macOS/Linux 的 `fcntl`。没有相应执行能力时，由 Agent 按同样规则维护私有断点。

脚本只记录计划、提交断点和核对结果，不控制浏览器、不读取短信、不执行兑换。运行状态保存在仓库外的私有任务目录。用法见 [状态脚本说明](references/transaction-state.md)。
