# 话费规则

只处理**本机话费直充**。所有面额、积分和资格以本次登录后的页面为准；以下是实测观察和判断规则，不是固定商品表。

## 入口

`apps.telefen.com/jycalls/?channelCode=HGOKHD`

页面直接显示：

- 页头脱敏号码
- `可用积分: N 积分`
- `充值号码：<完整号码>`（仅用于核对，不写入公开证据）
- 面额列表与所需积分
- 兑换规则

## 实测样本（2026-10-21，浙江，3 星）

| 面额 | 积分 |
|---|---|
| 10 元 | 1000 |
| 20 元 | 2000 |
| 30 元 | 3000 |
| 50 元 | 5000 |
| 100 元 | 10000 |

**面额随账号、省份和渠道变化，必须每次读取。** 其他账号出现过不同组合，不能把上表当全国统一价格。

## 页面规则（原文要点）

- 仅限电信积分充值，不支持现金；积分不足无法充值。
- 积分兑换话费仅在**当月 5–31 日**支持，其余时间不支持。
- **仅为登录号码充值**；副卡共享按各省规则，部分省份主卡不能共享。
- 积分直充话费不可转、不可退、不支持提现。
- 到账时间需登录 189.cn 营业厅查充值缴费记录/余额。
- 不开发票。

## 必须区分三种“话费”

1. **直充话费**：一次扣积分，充到本机话费余额。**本技能默认只做这一类。**
2. **分期返还话费**：可能一次扣完积分、按多月返还；不能承诺立即到账，本技能不默认办理。
3. **业务抵用金**：只限指定业务，不等同通用话费余额，本技能不默认办理。

## 不要做成“固话专享”

PC 商城搜索「话费」可能返回「话费 X 元（固话专享）」。那是固话商品，不是本机移动话费。本技能只走移动版话费专区 `jycalls`。

## 下单前核对清单

- [ ] 充值号码就是当前登录号码
- [ ] 面额与所需积分
- [ ] 可用积分是否足够
- [ ] 现金补款是否为 0
- [ ] 是否在 5–31 日时间窗
- [ ] 到账方式是否为一次直充
- [ ] 已有本笔面额授权，下单前告知成本与不可退；条件未变不重复确认

任何一项不明，先停下补读页面或让用户决定，不用旧样本补齐。
