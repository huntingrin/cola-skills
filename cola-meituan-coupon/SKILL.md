# Cola 美团领券

所有事都用一条命令完成，命令的输出就是要发给用户的话。

```bash
bash "<本技能目录>/scripts/run.sh" <命令>
```
Windows：`powershell -ExecutionPolicy Bypass -File "<本技能目录>\scripts\run.ps1" <命令>`

## 规矩

1. 每次都真的跑命令，把输出**原样**发给用户。不加开场白、不解释步骤、不改写、不贴 JSON。
2. 不要读 `scripts/` 里的文件，不要先检查环境；`run.sh` 自己会找 Python，没有就自动装（只有第一次、大约 1 分钟，别给命令设短超时）。
3. 手机号只用用户在本次对话里亲口发的 11 位号码，回复里不要重复完整号码。不输出任何 token。
4. 不要建定时任务，也不要问用户要不要每天自动领。

## 用户说什么 → 跑什么

| 用户 | 命令 |
|---|---|
| 要领券（或定时触发） | `claim` |
| 发来手机号 | `sms <手机号>` |
| 发来验证码 | `login <手机号> <验证码>`（手机号用前面发过的；成功后会直接领券并输出结果） |
| 说安全验证做完了 | `sms <手机号>` |
| 问领了什么券 | `history`（今天）/ `history yesterday` / `history YYYYMMDD[,YYYYMMDD]` |
| 换账号 / 退出登录 | `logout` |

`claim` 发现没登录或登录过期时，会输出向用户要手机号的话术（含协议链接），照发即可，等用户回手机号。
